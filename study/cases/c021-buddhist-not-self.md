## Expected context need

Expected context: **Argument**. The argument may help readers identify what would connect rejecting identification with the aggregates to a denial that persons exist in any ordinary sense.

## Possible misreading

There are no persons in any ordinary sense.

## Reader question

What would an argument have to establish to move from rejecting identification with the aggregates to the comparison statement?

## Draft answer guide

One would need to show that rejecting these identifications rules out every ordinary sense in which persons exist. That does not follow from rejecting these identifications alone.
