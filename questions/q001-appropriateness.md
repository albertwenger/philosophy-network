# What fixes appropriateness?

The [mean proposal](../proposals/p001-aristotle-mean.md) uses an evaluative
standard. What makes that standard informative enough to guide a new case?

The study should test whether linked concepts clarify the criterion or merely
move the difficult word elsewhere. A definition that points back to the same
question can be navigable without yet explaining anything.

This is an editor’s question, not an objection attributed to a historical
critic. It records a dependency to investigate, not a refutation.
